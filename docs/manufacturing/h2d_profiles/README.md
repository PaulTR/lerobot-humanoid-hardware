# Bambu H2D Print References

Reference `.3mf` projects and screenshots for the most critical printed parts.

Files:
- `shin_tibias_example.3mf` + `shin_tibias_print_example.png`: shin/tibias print setup.
- `thigh_femur_example.3mf` + `thigh_print_example.png`: thigh/femur print setup.
- `hip_example.3mf` + `hip_print_example.png`: hip print setup.

Scope note:
- These references are provided for `shin`, `thigh`, and `hip` only.
- Other parts are generally straightforward with the baseline settings from `docs/manufacturing/printing_guide.md`.
