# Assembly Photos (Mounted Robot)

This folder stores mounted-robot reference photos used by the assembly guide.

## File map

- `leg_full_view.jpg`: full leg overall context.
- `torso_detail.jpg`: torso assembly details.
- `hipy_detail.jpg`: hipy-side detail (hipz naming in repo).
- `hipz_detail.jpg`: hipz detail.
- `thigh_detail.jpg`: thigh/femur detail.
- `knee_detail.jpg`: close-up knee detail.
- `knee_mechanism_view_1.jpg`: knee mechanism angle 1.
- `knee_mechanism_view_2.jpg`: knee mechanism angle 2.
- `knee_mechanism_view_3.jpg`: knee mechanism angle 3.

Use these photos as visual context, and always cross-check final orientation against the Onshape assembly.
